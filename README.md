# TreeSize (clone moderne)

Application web inspirée de TreeSize pour analyser rapidement l'espace disque de vos lecteurs.

## Fonctionnalités

- Détection automatique des lecteurs/disques montés.
- Sélection d'un ou plusieurs lecteurs.
- Analyse de la taille des répertoires présents à la racine de chaque lecteur sélectionné.
- Graphique comparatif de l'occupation de chaque lecteur analysé.
- Tableau détaillé des dossiers racine et de leur taille.

## Lancer l'application

```bash
python app.py
```

Puis ouvrir : `http://localhost:8000`.
